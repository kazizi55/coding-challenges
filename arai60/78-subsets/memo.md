### Step 3

#### Solution 1

- ビット全探索を使う解法。
- 1 << n を使うことで1をnだけ左にビットをずらすことができる == 2^nにできるので、numsに対して入れる・入れないの組み合わせの数を簡単に求められる。
- bit_mask & (1 << i) とすることで、iが1になっているかどうかを求められる。なんでこれが嬉しいかというと、1になっている時だけsubsetにappendしたいから
- 1 << nのループの中でlen(nums)のループを回す
  - イメージとしては、3つの球を袋に入れるときに、入れる・入れないを8通りで考える場合に、それぞれの球を入れるかの選択は毎回3回だけで事足りると言う感じ。

#### Solution 2

- 再帰を使うバックトラックの解法。
- subsetにnums[index]をappendするかしないかでtraverse_nums(index, subset)の子分を2人作って探索して行っている。
- if index == len(nums)をベースケースにしているのはlen(nums) - 1も探索しているから

#### Solution 3

- stackを使うバックトラックの解法。
- Solution 2と考え方は同じだが、こっちの方が見通しが良くてわかりやすい。

- が、個人的に上から順番に書いていくなら再帰の方がわかりやすいと感じるようになった。stackを書く時点でこれはindexとsubsetになるから〜とか。好みだろう。
